### 🚀 Things I've Built

**1. 💬 Django Real-Time Chat Application**

A real-time messaging application built with Django Channels, WebSockets, Redis and PostgreSQL.

- Multi-user messaging without page reloads
- Authentication and session management
- Cloudinary-based media storage
- Docker-based setup and Render deployment

🔗 [Live Demo](https://django-real-time-chat-application.onrender.com) | [Source Code](https://github.com/divyanshh22/Django-Real-Time-Chat-Application)

**2. 📦 Inventory & Order Management System**

A Django REST Framework application for managing inventory, orders and stock operations.

- Token-based authentication and role-based access control
- Automated low-stock alerts using Celery Beat and Redis
- Immutable stock movement records
- PDF invoice generation using ReportLab

🔗 [Live Demo](https://inventory-order-management-system-gttj.onrender.com) | [Source Code](https://github.com/divyanshh22/Inventory-Order-Management-System)

**3. 🎓 College ERP System**

A full-stack college management system built with Django, DRF and PostgreSQL.

- Role-based dashboards for students, faculty and administrators
- Attendance tracking and automated 75% shortfall alerts
- Exam marks, weekly timetables and faculty reports
- Supports 50+ students, 13 faculty and 15 courses

🔗 [Live Demo](https://college-erp-system-fkr1.onrender.com) | [Source Code](https://github.com/divyanshh22/College-ERP-System)

**4. 🛒 Full-Stack E-Commerce Platform**

An e-commerce application built with Django and PostgreSQL.

- Product catalog, shopping cart and checkout
- Discount coupons and refund requests
- Stripe payment gateway integration (test mode)
- Authentication using django-allauth
- Admin dashboard for products, orders and coupons

🔗 [Live Demo](https://full-stack-e-commerce-platform-6gy3.onrender.com) | [Source Code](https://github.com/divyanshh22/Full-Stack-E-Commerce-Platform)
